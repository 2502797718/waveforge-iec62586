# 标准映射与追溯

> 本文把 WaveForge 的场景名追溯到 **IEC 62586-2 的条款号**、所用**信号原语**和**预设默认值摘要**。
> 只记录条款编号、原语名称与我们自己的默认参数，不复制标准正文、整表或扫描页。
>
> **版权声明**：IEC 62586-2、IEC 61000-4-7、IEC 61000-4-15、IEC 61000-2-4 等标准的原文、表格与图示受版权保护。
> 标准原文需自行向 IEC 或授权渠道获取；本文不替代标准，也不能据此判断设备是否符合标准。
>
> 相关文档：[信号目录](signal-catalog.md) · [输入格式](input-format.md) · [架构](architecture.md)

## 1. 引用版本

| 标准 | 版本 | 在本项目中的用途 |
|---|---|---|
| IEC 62586-2 | 2017 + AMD1:2021 | 测试条款编号与激励需求的来源 |
| IEC 61000-4-7 | 2002 + A1:2008 | 谐波/间谐波测量与精度背景（仅背景） |
| IEC 61000-4-15 | 2010 | 闪变试验参数背景（仅背景） |
| IEC 61000-2-4 | 2024 | Class 3 兼容水平背景（仅背景） |

本项目的预设只使用**条款编号**与**信号结构**；具体默认值是我们为可复现回归设定的激励值。

## 2. 原语代号

| 代号 | 信号原语 | 对应实现 |
|---|---|---|
| `STEADY` | 稳态正弦，逐通道幅值/相位 | 基波分量 / 旧 `signal` |
| `FREQ-TRI` | 频率三角轮廓，相位积分 | `freq_triangle` 或 `signal.frequency` |
| `FREQ-LIN` | 频率线性轮廓 | `freq_linear` |
| `AM-SINE` | 正弦调幅 `1 + m·cos(2πfm t + φ)` | `amp_sine` |
| `AM-RECT` | 矩形调幅，占空比可设 | `amp_rect` |
| `AM-TRI` | 幅值三角包络 | `amp_triangle` |
| `AMP-STEP` | 幅值阶跃（可分段/过零切换） | `segments[]` / `amp_step` |
| `AMP-SEQ` | 多段幅值序列 | `segments[]` |
| `H` | 谐波叠加，相对基波 | `WG_COMP_HARMONIC` |
| `IH` | 间谐波，`order` 可为小数 | `WG_COMP_INTERHARMONIC` |
| `TONE` | 绝对频点载波 | `WG_COMP_TONE` |
| `H-RAMP` | 谐波幅值三角斜坡 | 谐波分量 + `amp_triangle` |
| `IH-RAMP` | 间谐波幅值三角斜坡 | 间谐波分量 + `amp_triangle` |
| `LONG` | 长时稳态 / 提供性 | 同一求值核心，时长可覆盖 |
| `EVENT-100ms` | 100 ms 短事件 | `segments[]` 或 `amp_step` |

## 17. 状态与默认值说明

1. 表中所有数值都是 **WaveForge 的预设默认值**，可被 `--freq/--amp/--phase/--duration`、JSON 或 C API 覆盖。
2. `NO_DEFAULT` / `CUSTOM` / `EXCLUDED` 只描述“预设是否带默认值”，不描述发生器能力。
3. 场景的完整状态清单与每项默认摘要见 [信号目录](signal-catalog.md)。
4. 标准原文的判据、容差、测量不确定度不在本项目范围；本表只用于生成激励。

## 18. 追溯方式

- 场景名 → 条款号 → 原语：本表。
- 场景名 → 默认参数：`wg gen --test <ID>` 或 `wg list` 的说明列。
- 实际生成参数：`<输出>.manifest.json` 的 `signal` / `program` / `segments`。
- 数学正确性：`tools/verify.py` 与 `tools/check_acceptance.py`，见 [校验](verification.md)。
