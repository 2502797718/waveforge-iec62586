# 信号目录与预设

> 本文按 IEC 62586-2 的条款结构（6.1–6.17）整理 WaveForge 能表达的信号能力与内置预设。
> **所有数值都是预设默认值，不是标准原文，也不是能力上限。** 幅值、频率、相位、调制深度、范围、周期、时长与通道都可覆盖。
> 标准原文需自行获取；本文不替代标准，也不作 IEC 合格判定。
> 相关文档：[标准映射](standard-mapping.md) · [输入格式](input-format.md) · [架构](architecture.md)

## 1. 状态约定

| 状态 | 含义 | `wg gen --test` 实际行为 |
|---|---|---|
| `DEFAULT` | 标准默认值齐备 | 直接生成 |
| `CUSTOM` | 标准未给数值，或属通道/能力选择项 | 返回 `CUSTOM: <字段路径>`，需用户补参数 |
| `NO_DEFAULT` | 缺标准数值或设备声明 | 返回 `NO_DEFAULT: <字段路径>`，不产生文件 |
| `EXCLUDED` | 不属波形发生器职责 | 返回 `EXCLUDED: <原因>` |

`NO_DEFAULT`/`CUSTOM` **不是能力缺失**：用 JSON `program` 或 C API 补齐后即可生成。

`wg list` 共 104 行：101 个场景 + 3 个频率别名。状态分布：

| 状态 | 数量 | 说明 |
|---|---|---|
| `DEFAULT` | 81 个场景 + 3 个别名 | 可直接生成 |
| `CUSTOM` | 4 | A1.4.1、A6.1.3、A7.1.3、A9.1.6 |
| `NO_DEFAULT` | 15 | 见各节 |
| `EXCLUDED` | 1 | A6.1.6 |

> `wg list` 的说明列会写出 `CUSTOM:` / `NO_DEFAULT` / `EXCLUDED:` 前缀；`DEFAULT` 项没有前缀。

## 2. 通用可覆盖项

所有场景都接受：

| 覆盖项 | 作用 |
|---|---|
| `--system 50\|60` | 切换预设频率（50 Hz / 60 Hz 两套默认） |
| `--duration` | 覆盖总时长（0.001–7200 s） |
| `--freq` | 覆盖基波频率 |
| `--amp` | 覆盖逐通道幅值 |
| `--phase` | 覆盖逐通道相位 |
| `--harmonics` / `--interharmonics` / `--tone` | 覆盖/追加分量 |
| `--mod` | 给基波追加正弦/矩形调幅 |
| `--rate` / `--frame` / `--format` / `--start` | 采样与输出参数 |
| `--out` | 输出文件 |

复杂调制（线性/三角/阶跃、频率轮廓、幅值阶跃事件）请使用 JSON `program`。

使用方式示例：

```sh

```

其中 `channels` 必须显式包含 `Ia/Ib/Ic`，`nominal` 按实际额定电流设置。

## 17. 预设不覆盖的内容

1. 标准判据、测量不确定度、合格阈值：属于被测设备与实验室。
2. ADC、模拟前端、抗混叠、互感器、真实时钟：属于硬件。
3. 环境试验（6.12）：需要温箱/可调电源。
4. 标准原文中的整表数值：本目录只保留生成所需的默认摘要。

## 18. 覆盖与追溯

- 每个 `DEFAULT` 场景都可以只改一个字段：`--freq`、`--amp`、`--phase`、`--duration` 等。
- 缺省值只在用户未给出时生效；manifest 记录最终值。
- 场景名与条款的逐项对应见 [标准映射](standard-mapping.md)。
- 全部预设的数学验收口径见 [校验](verification.md)；不涉及 IEC 合格判定。
